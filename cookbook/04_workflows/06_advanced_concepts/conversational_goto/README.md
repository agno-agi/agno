# Conversational Sticky Steps + Goto

Demonstrates first-class Workflow primitives for multi-turn agent steps and
backtracking (`complete_step` / `goto`), as discussed in
[issue #9128](https://github.com/agno-agi/agno/issues/9128).

## Files

- `basic_booking.py` — ticket booking flow with sticky destination/departure steps

## Run

```bash
.venvs/demo/bin/python cookbook/04_workflows/06_advanced_concepts/conversational_goto/basic_booking.py
```
