# OpenAI Decisions Cookbook

OpenAI's Decisions API answers typed questions with probabilities instead of generating text.

### 1. Export your `OPENAI_API_KEY`

```shell
export OPENAI_API_KEY=***
```

### 2. Install libraries

```shell
uv pip install -U openai agno
```

### 3. Ask typed questions

```shell
python cookbook/90_models/openai/decisions/basic.py
```
