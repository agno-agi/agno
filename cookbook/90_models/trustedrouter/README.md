# TrustedRouter

Cookbook examples for `cookbook/90_models/trustedrouter`.

[TrustedRouter](https://trustedrouter.com) is an OpenAI-compatible router. Set your
API key first:

```bash
export TRUSTEDROUTER_API_KEY=***
```

Run examples with:

```bash
.venvs/demo/bin/python cookbook/90_models/trustedrouter/<example>.py
```
