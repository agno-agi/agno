# Lantern exports

Fictional product documentation, revision 1. Lantern is a shared project notebook.
Workspace owners and admins can export a workspace from Settings > Data > Export.
Exports contain Markdown pages and a CSV task list. Download links expire after
24 hours. If a link expires, create a new export from the same menu. Members can
read shared pages but cannot export the workspace. Export jobs usually finish
within ten minutes; this is guidance, not a service guarantee.
